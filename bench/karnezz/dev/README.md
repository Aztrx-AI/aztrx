# Notes (development fixture)

A tiny notes app used only to smoke-test the Karnezz agent interface. It is not an evaluation task.

- Add a note by typing its text and pressing "Save note".
- Every saved note appears in the list, newest last, with a "Delete" button.
- The heading shows how many notes you have: "N notes".
- Deleting a note removes it and lowers the count by one.

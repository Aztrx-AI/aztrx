# Aztrx — marketing site

The landing page for [Aztrx](https://aztrx.app), the runtime stress-tester CLI
(see the repo root). Next.js 16 + Tailwind v4.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

See [`DEPLOY.md`](./DEPLOY.md) for Vercel + domain setup.
